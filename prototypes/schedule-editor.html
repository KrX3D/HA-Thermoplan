Schedule editor prototype

Standalone test page (not part of the integration). Open this file in a browser; nothing is saved. Data format is the same as the integration: [start, end, target] in minutes, end up to 2880 (next day), null = off.
Drag on an empty area of a day to draw a block. Drag a block to move it, drag its edges to resize. Click a day label to edit that day below. Delete removes the selected block. Hatched blocks continue from the previous night.
